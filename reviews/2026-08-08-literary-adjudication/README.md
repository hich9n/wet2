# بستهٔ داوری ادبی دومرحله‌ای

این پوشه کانون، حافظهٔ فعال بازنگری یا مجوز تغییر رمان نیست. هدفش گرفتن دو حکم
مستقل با یک پروتکل مشترک است:

- `CLAUDE_CODE_PROMPT.md`: دستور کامل داور؛
- `agent-dossier.md`: همهٔ یافته‌های ایجنت‌های دور پیش، به‌صورت گزارش‌نامهٔ بخش‌بندی‌شده؛
- `claude-blind-pass.md`: خروجی میانی که Claude Code باید پیش از خواندن کانون بسازد؛
- `claude-verdict.md`: حکم نهایی Claude Code؛
- `sol-literary-verdict.md`: حکم نهایی داور تازهٔ Sol/high.

## ترتیب اجباری

1. داور فقط `AGENTS.md` و متن‌های `drafts/chapters/` را می‌خواند.
2. بدون جست‌وجوی واژه‌ای و بدون کانون، خوانش اول را در فایل blind-pass ثبت می‌کند.
3. سپس هفت سند فعال، لجر و `agent-dossier.md` را می‌خواند.
4. حکم نهایی را می‌نویسد.

گزارش‌ها شاهد ثانویه‌اند. توافق داورها نیز به‌تنهایی اثبات کیفیت یا ضعف متن نیست؛
ایجنت اصلی باید اختلاف‌ها را با اجرای زنده بررسی کند.
