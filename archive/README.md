# آرشیو توسعهٔ «شاهِد خیس»

این پوشه حافظهٔ تاریخی پروژه است، نه منبع حقیقت جاری. ایجنت‌ها فقط با دستور صریح نویسنده حق خواندن یا جست‌وجوی آن را دارند. برای نگارش، نقد و بازنویسی عادی از `docs/story/canonical.md` آغاز کن.

## محتوا

- `canon-reset-2026-08-08.md`: روایت تصمیم‌محورِ چرایی، روش و نتیجهٔ بازپایه‌گذاری کانون، حافظه و اسکیل‌ها.
- `decision-history.md`: خلاصهٔ انسانیِ دوره‌ها، تصمیم‌های برگشته و نتیجهٔ نهایی آن‌ها.
- `pre-cleanup-2026-08-08/`: تصویر کامل اسناد کانونی، پنج اسکیل و همهٔ گزارش‌های بازنگری پیش از بازپایه‌گذاری.
- `pre-cleanup-2026-08-08/MANIFEST.md`: خط پایه، شمار فایل‌ها، هش دست‌نوشته و قرارداد بازیابی.

دست‌نوشته در آرشیو کپی نشده است. نسخهٔ متناظر آن در کامیت مبنا ثبت شده و هش هر ۲۶ واحد در مانیفست آمده است.

## سیاست رجوع

آرشیو برای پاسخ به پرسش‌هایی مانند «این تصمیم چگونه عوض شد؟» یا بازیابی یک مادهٔ حذف‌شده است. وجود یک ایده یا حکم در آرشیو، آن را کانونی یا مجاز برای بازگرداندن نمی‌کند. اگر آرشیو با هستهٔ زنده فرق دارد، هستهٔ زنده مرجع است مگر نویسنده صریحاً تصمیم دیگری بگیرد.
